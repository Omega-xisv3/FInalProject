What is a Code Editor?

Explanation

A code editor is a text editor specifically designed for writing and editing source code. It provides features like syntax highlighting, code completion, and debugging tools.

Some features of Visual Studio Code I found useful

IntelliSense

IntelliSense offers Suggestions based on your previous code. I've found it really useful for longer assignments as it helps me build the skeleton of my code.

Closing Tags and Emmet snippets

Visual Studio Code automatically closes tags for you, which has saved me a lot of time. Emmet snippets have also made the process ten times faster.
