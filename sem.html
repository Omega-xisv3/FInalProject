What is semantic HTML?

Semantic HTML uses tags such as <header>, <nav>, and <main> to make sure my websites have a good structure. I use semantic HTML to create more accessible and maintainable websites. I like to use the header for my main title so it's the first thing viewers see when they open the page. I use the nav section for my navigation links and I put the remaining content within the main section.
